# 比赛要求与证据矩阵

## 使用方法

本文件把当前已读比赛规则与 Flux Evidence Lab 的实现、演示证据和人工确认点放在同一张表中。规则来源为参赛方提供的[比赛说明文档](https://scnv1siu30yw.feishu.cn/docx/FEk2dSsunoF52KxFJF9cihxTnPd)。由于规则可能修订，提交人必须在截止前填写规则版本或核对日期，并以报名后台当时显示的最终要求为准。

```text
规则版本 / 修订号：TBD
最后人工核对日期：TBD
核对人：TBD
报名后台项目 ID：TBD
```

状态含义：

- **已有执行证据**：当前源码、实际测试或已生成产物能够支持该陈述；
- **文档/脚本就绪**：材料已准备，但视频、现场演示或外部提交尚未发生；
- **部分满足**：边界已有实现，但仍有比赛口径或人工流程待确认；
- **TBD**：没有足够证据，提交前不得写成已完成。

## 参赛方规则摘录（待官方版本核对）

以下是从参赛方提供、尚未锁定版本文本摘录的评分与门槛，不是官方最终确认。规则文档按 100 分描述，但表内权重合计为 `95%`；本项目保留该原文不一致，不自行补造缺失的 `5%`。

| 官方评分项 | 权重 | 本项目主要证据 |
| --- | ---: | --- |
| 问题定义与场景价值 | 35% | 面向数字资产研究、模型风险与合规审计的证据错配痛点；目标用户和闭环工作流 |
| 技术实现与创新性 | 30% | 真实四源采集、版本化概率模型、确定性风控、原始值变换重算、哈希链、签名与离线重放 |
| 隐私、安全与可验证性 | 15% | 无客户数据/账户凭据、Paper-only、来源/价格/coverage 绑定、语义篡改检测 |
| 合规意识与负责任创新 | 10% | 无真实资金和外部路由、跨境与第三方披露、误差/幻觉风险、免责与人工责任点 |
| 完成度与演示表达 | 5% | 高密度评委控制台、2026-09-03 Windows x64 便携候选包历史技术验收 PASS、当前源码复现记录、双视口 UI 历史验收、3 分钟脚本与 5–8 分钟现场 runbook；视频和排练仍 TBD |
| **表内合计** | **95%** | **规则原文不一致，待主办方或报名后台最终确认** |

> **产物边界：** 当前 GitHub checkout 与 2026-09-03 的外部 Windows portable candidate 是不同产物。后者的 93/93 manifest、94 个文件和 30/30 测试只作为历史外部证据保留；当前 checkout 不包含 `runtime/node.exe`、`promo/offline-kit/` 或候选 ZIP，当前结果见 `docs/TEST_REPORT.md` 的源码 checkout 复现记录。

当前建议主申报方向为 **方向 C：可验证 AI 推理审计 / 量化因子 Agent**，并覆盖部分 **方向 B：采集 → 判断 → 解释 → 响应建议/模拟执行闭环**。方向 C 的结构化审计要求由模型版本、数据范围、推理/验签耗时、产物体积、证明附件、局限和免责共同覆盖；最终方向仍以官方最终版本和团队提交决定为准。

参赛方文本列出的三项核心评审问题是：是否真的能演示；去掉 AI 后关键能力是否消失；是否解决真实数字金融/Web3 痛点且合规边界清楚。

参赛方文本列出的技术准入门槛（待官方版本核对）：核心路径必须在测试网、CDE 或可复现本地环境真实跑通；AI 必须实质改变感知、风险判断、策略、审计或 Agent 决策；必须形成区块链/Web3 或数字金融闭环；所有隐私/可验证声明必须能演示和复核。测试网、模拟资产、合成数据和历史公开链上数据允许，真实高价值主网资产禁止进入比赛演示。

## 5–8 分钟现场问答准备

评委若追问，应使用以下短答，且以现场运行结果为准：

| 问题 | 回答边界 |
| --- | --- |
| 为什么是 AI Agent？ | 模型直接从证据生成候选动作，风控、订单状态和验证器形成可执行闭环；不是聊天界面或摘要包装 |
| 为什么是金融项目？ | 核心问题是数字资产研究决策的证据错配、模型风险与审计，而非泛用工作流 |
| 可以交易 BTC 吗？ | 不可以。当前只生成本地 Paper 结果，没有交易所、钱包、账户或真实资金路径 |
| 签名是否证明数据真实？ | 不证明。它只证明报告签名后未被修改，上游内容仍可能错误、延迟或不完整 |
| 模型会不会幻觉？ | 没有生成式文本路径，但结构化模型仍会误判、受缺失/错误数据影响，且概率未完成现实校准 |
| 为什么需要人工？ | 人工选择场景、解释结果并负责外部提交；当前没有真实金融动作。任何未来 Live 动作都必须另设人工批准 |
| 是否满足 70%？ | 目标是满足，但当前核算仍为 TBD；只展示证据支持的赛期新增内容，不把目标说成结果 |
| 跨境数据如何处理？ | 请求不发送客户或账户数据，但外部服务可能跨境处理公开查询和网络元数据；正式部署前需按主体所在地复核 |
